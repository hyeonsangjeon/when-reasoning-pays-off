# Task 024 replay validation

This directory is generated by `scripts/replay_ptu_utilization.py` from explicit local JSONL inputs. The replay is offline and uses the Guide admission-reservation formula with a fitted continuous leak constant.

## Artifacts

- `calibration.json`: fitted leak constant, official-spec inputs, capacity-source labels, optimizer details, diagnostics, and residual summaries.
- `validation.md`: source caveats, calibration summary, residual summaries, and methodology notes.
- `runs/.gitkeep`: placeholder for optional future replay-run snapshots.

Charts are written to `results/replay-validation/`:

- `predicted_vs_observed_429_timestamps.png`
- `predicted_vs_observed_retry_after_ms.png`

The outputs are a candidate input for capacity planning with source-run caveats, not a generalized predictor across deployments.
