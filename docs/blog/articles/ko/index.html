블로그 / 근거 노트

글

근거 대시보드는 검증 기록이고 글은 의사결정 과정을 설명합니다. 각 글은 질문으로 시작해 답에 근거가 된 차트를 제시하고 운영자를 위한 시사점으로 마무리합니다. 순서대로 읽어도 되고 필요한 계층으로 바로 이동해도 됩니다.

읽기 경로 1. 개요 2. 실험 회고 3. 근거 토픽 4. 브리지 5. 운영 근거 대시보드

글의 흐름은 주장부터 실무까지 이어집니다. 개요 글은 하나의 메시지와 근거의 경계를 먼저 잡습니다. 실험 회고는 그 근거가 어떻게 만들어졌는지를 타임라인과 질문별 이야기로 풀어냅니다. 근거 토픽은 측정한 각 구간을 하나씩 엽니다. 브리지 글은 측정을 다루던 서술이 프로덕션 운영으로 넘어가는 지점을 짚습니다. 운영 글은 같은 측정 습관을 복구, 캐시 라우팅, 보존, 마이그레이션 사이징 같은 일상 운영에 적용합니다. 이 모든 글의 밑바탕에는 근거 대시보드가 있어, 모든 주장이 근거로 삼은 정리된 테이블과 소스 차트를 담고 있습니다.

개요 글: 같은 토큰 단가, 다른 청구서

안내에 따라 공개 차트 데이터 스냅샷을 읽습니다. 추론 강도가 어디서 지출을 낭비하고 어디서 시도할 가치가 있는지, 또 왜 숨은 추론 토큰을 명시적으로 예산에 넣어야 하는지를 봅니다.

개요 글 읽기

실험 회고: 숫자가 나오기까지

계층별로 읽기 전에 세 실험 전체를 하나의 이야기로 살펴볼 수 있습니다. 회고 허브는 타임라인(언제 무엇이 어긋났나)과 질문별 회고(왜 실험했고 무엇을 배웠나) 두 축으로 근거를 훑고 맨 위 명령어 한 줄로 자격증명 없이 바로 재현합니다.

회고 허브

세 작업 형태를 관통하는 하나의 이야기: 타임라인과 질문별 두 축으로 근거를 탐색합니다.

회고 허브 읽기

exp001, 짧은 사실 작업

Null 케이스이자 바닥 기준점입니다. 세 벤치마크 중 유일하게 실측으로 추론이 제값을 하지 못하는 구간을 확인합니다. none이 이미 gpt-4o를 앞서고 강도 손잡이를 더 올려도 달라지는 것이 없습니다.

실험 노트 읽기

exp002, 다단계 추론

다단계 작업의 천장 사례입니다. 사전 등록한 예측이 어디서 틀렸는지 입력, 산출물, 비용, 품질을 하나씩 살펴봅니다.

실험 노트 읽기

exp003, 툴 사용 에이전트

툴 에이전트 혼합 사례입니다. 바닥이 none이 아니라 low로 한 칸 올라가며 gpt-4o가 도구를 남용하는 지점을 짚습니다.

실험 노트 읽기

exp004, 스필오버 정책 시뮬레이션

강도 삼부작 뒤 첫 운영 실험(Phase 1). 부하가 한계 수준인 상황에서 미리 대비하는(proactive) 스필오버가 사후 반응(reactive)보다 캐시를 더 지키는지 겨뤘고 답은 무승부에 가까웠습니다.

실험 노트 읽기

exp005, 이중 배포 스필오버

물리적으로 분리된 캐시를 가진 실제 두 배포로 내린 Phase 2 판정입니다. 미리 대비하는(proactive) 스필오버가 사후 반응(reactive)보다 캐시를 더 지키는지 다시 겨뤘고 이번엔 격차가 약 6배로 벌어졌습니다.

실험 노트 읽기

exp006, 캐시 키 버킷 쪼개기

라이브 gpt-5.2 PAYG에서 prompt_cache_key를 1개에서 8개로 쪼개면 캐시 히트가 살아나는지 물었습니다. 문서의 ‘버킷당 약 15요청’ 한도는 물렁했고 진짜 지렛대는 카디널리티가 아니라 보존 정책이었습니다.
