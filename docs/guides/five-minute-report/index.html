Five-minute offline provenance report

Generate a useful local report.html from strict operational metadata without Azure credentials, uploads, telemetry, a browser uploader, or a live service call.

1. Scope and evidence boundary

The command-line interface (CLI) measures tokens, cache accounting, latency, HTTP status behavior, and models pay-as-you-go (PAYG) cost from a pinned snapshot. An optional narrow section for sizing provisioned throughput calls the repository's existing sizing calculator.

Quality is NOT_MEASURED. Usage metadata cannot prove that an effort change preserves quality. The report recommends a controlled experiment instead.

2. Install

Use Python 3.11 or later. No Azure account is required, and the analyzer makes zero runtime network calls. Initial dependency installation can need package-index access unless dependencies are cached.

python3 -m venv .venv
. .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install .
reasoning-payoff --version

3. Run the credential-free sample

reasoning-payoff analyze examples/five-minute/usage.jsonl \
  --workload examples/five-minute/workload.yaml \
  --out report

Open report/report.html directly from disk. The output directory must be absent or empty.

report/
  report.json
  report.md
  report.html
  policy.json

4. Initialize a portable sample

reasoning-payoff init --out .reasoning-payoff
reasoning-payoff analyze .reasoning-payoff/usage.jsonl \
  --workload .reasoning-payoff/workload.yaml \
  --out report

Packaged resources make init independent of the current working directory. It writes usage, workload, PAYG, PTU, and density snapshots that match the committed examples byte for byte.

5. Bring your own workload

Export only the fields in the contract. Do not export prompt or completion content, endpoints, hostnames, IP addresses, subscription or tenant IDs, credentials, request or user IDs, or email addresses.

reasoning-payoff analyze my-analysis/usage.jsonl \
  --workload my-analysis/workload.yaml \
  --out report

6. UsageEnvelope JSONL v1

Required fields; unknown fields fail closed.
FieldContract
timestampRFC 3339 string with timezone
providerazure-openai
modelSafe model identifier
reasoning_effortnone, minimal, low, medium, high, xhigh, or max; support varies by model
input_tokensNon-negative integer
cached_input_tokensCached subset of input
output_tokensFull output including reasoning
reasoning_tokensLabeled subset of output
latency_msNon-negative client-side latency
status_codeInteger 100-599
retry_after_msNon-negative number or null

Numeric strings are rejected. Cached input cannot exceed input, and reasoning cannot exceed output. The reader streams and hashes JSONL under bounded file, line, and row limits.

7. WorkloadSpec YAML v1

schema_version: "1.0.0"
name: my-workload-v1
method:
  id: usage-profile
  version: "1.0.0"
pricing:
  snapshot_id: my-payg-snapshot
  snapshot_file: pricing.yaml
quality:
  status: NOT_MEASURED
thresholds:
  max_429_rate: 0.05
  max_p95_latency_ms: 5000
  min_cached_input_ratio: 0.25
  max_reasoning_output_ratio: 0.50

The report-visible name is a safe slug. Snapshot files are safe relative paths beside the workload file.

Optional PTU sizing

ptu_sizing:
  expected_rpm: 120.0
  mean_max_output_tokens: 1024
  target_utilization: 0.70
  pricing_snapshot_id: my-ptu-pricing-snapshot
  pricing_snapshot_file: ptu-pricing.yaml
  density_snapshot_id: my-density-snapshot
  density_snapshot_file: density.yaml

When absent or inapplicable, PTU sizing is explicitly NOT_MODELED. The calculator applies the pinned minimum, maximum, and regional scale increment, rounding up before it models cost and crossover.

8. Artifacts and provenance

  • report.json: input hashes, versions, snapshots, measurements, boundaries, conclusions, and policy.
  • report.md: deterministic review summary.
  • report.html: self-contained, script-free, escaped local report with inline CSS.
  • policy.json: review-only candidates with evidence, assumptions, confidence, source rows/selectors, and immutable hashes. auto_apply is false.

Every conclusion records evidence, assumptions, confidence, source rows, selector, method/schema/CLI versions, claim-registry hash, and pricing or PTU snapshot hashes when used.

9. Interpret measured and modeled values

  • MEASURED: derived directly from accepted rows.
  • MODELED: measured rows plus pinned snapshots and explicit assumptions.
  • NOT_MEASURED: no evidence supplied for the dimension.
  • NOT_MODELED: required inputs or applicability are absent.

Reasoning tokens are already part of output tokens and are billed once. Cache semantics vary by model or application programming interface (API). PTU is planning evidence, not proof of live capacity. A 429 rate does not identify one root cause.

10. Privacy and deterministic re-render

Errors expose line and field locations, never the rejected line, input path, or value. Artifacts are staged as a complete bundle. Re-rendering uses failure-recoverable directory replacement: a reported swap failure restores the previous bundle, and the next invocation recovers an abandoned backup or stage after interruption. Portable filesystems can still expose a brief rename gap, so this is not an atomic visibility guarantee.

A sibling .report.reasoning-payoff.lock proves bundle ownership. The CLI refuses to replace a four-file lookalike directory that lacks this marker.

reasoning-payoff report report/report.json
reasoning-payoff report report/report.json --out rerendered-report

12. Verify timing and byte stability

/usr/bin/time -p reasoning-payoff analyze \
  examples/five-minute/usage.jsonl \
  --workload examples/five-minute/workload.yaml \
  --out report
shasum -a 256 report/report.json report/report.md \
  report/report.html report/policy.json
reasoning-payoff report report/report.json
shasum -a 256 report/report.json report/report.md \
  report/report.html report/policy.json

The hash sets must match. The fresh-clone ceiling is five minutes; the bundled sample target is under 60 seconds.

Measured on 2026-08-20: the installed sample analyze command completed in 0.12 seconds. This excludes environment creation and dependency installation and is not a universal guarantee.
